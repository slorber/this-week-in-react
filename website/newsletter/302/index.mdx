## 💸 Sponsor {#sponsor1}

[![On-device AI for React & React Native](/emails/issues/302/nobodywho.png)](https://github.com/nobodywho-ooo/nobodywho)

**[On-device AI for React & React Native](https://github.com/nobodywho-ooo/nobodywho)**

NobodyWho is a library for running LLMs locally & offline on any OS. GPU-accelerated via Vulkan or Metal.

*   **Any LLM**: Gemma, Qwen, Mistral and more in .gguf format
*   **Type-safe tool calling**: automatically generates structured grammars from your function signatures
*   **Multimodal input**: provide image and audio information to your LLM
*   **Text-to-speech**: synthesize local WAV audio with Kokoro, Pocket TTS and Supertonic backends
*   **Speech-to-text**: transcribe audio into text with Whisper
*   **Voice Activity Detection**: know when to stop listening and start transcribing with Silero  
      
    Available for **React Native**, **Expo**, but also for Flutter, Swift, Kotlin, Python, Godot and in React very soon thanks **WebAssembly**.  
      
    **Star the** [**repo**](https://github.com/nobodywho-ooo/nobodywho) if NobodyWho is useful to you, it is how people find us ❤️

## 💸 Sponsor {#sponsor2}

[![Make Forms a Scalable Part of Your React App](/emails/issues/293/survey.jpg)](https://surveyjs.io/?utm_source=this-week-in-react&utm_medium=email)

**[Make Forms a Scalable Part of Your React App](https://surveyjs.io/?utm_source=this-week-in-react&utm_medium=email)**

Product teams need to launch new forms and update existing ones. Developers shouldn't have to edit fields, labels, and validation rules for every change. [**SurveyJS**](https://surveyjs.io/?utm_source=this-week-in-react&utm_medium=email) **provides a JSON-driven form library and an embeddable drag-and-drop form builder** for your React application.  

Customize SurveyJS components to match your UI with custom themes or ready-to-use *theme adapters for Bootstrap, shadcn/ui, and Material UI*.  
  
• Works with any backend and database  
• Fits your existing design system  
• Keeps developers in control of architecture and data  
  
Developers control the UI and data. Business users update forms visually without waiting for every change to be coded. 🚀
