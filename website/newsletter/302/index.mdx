## 📱 React-Native {#react-native}

![React Native 0.88](/emails/issues/302/react-native-088.jpg)

[**React Native 0.88**](https://reactnative.dev/blog/2026/10/19/react-native-0.88)

The new release is out with one of the largest runtime changes in years\! Events are now dispatched through the W3C [`EventTarget`](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget) API by default. This is the same model as on the web, making it possible to share event handling code between web and native. This opens the path to web-compatible imperative APIs in the future. And yet, it’s a third release with no user-facing breaking changes, after 0.83 and 0.86.

Other key highlights include:

- **SceneDelegate on iOS** \- support for the `UIScene` lifecycle required by the iOS 27 SDK, added additively.
- **Variable fonts** \- `fontVariationSettings` on `Text` and `TextInput`, on Android and iOS, in object or CSS string form.
- **ArrayBuffer for Java TurboModules** \- binary data no longer needs base64 or number-array encoding, and synchronous calls can borrow JavaScript memory instead of copying it.
- **Swift Package Manager improvements** \- still experimental, but iOS versions now come from the app's deployment target, and Xcode builds no longer break for libraries shipping their own `Package.swift`. 0.89 targets SwiftPM as the default.

![Expo SDK 58](/emails/issues/302/expo-sdk-58.jpg)

[**Expo SDK 58**](https://expo.dev/changelog/sdk-58)

A React Native release is not enough\! Expo SDK 58 is out with React Native 0.88, built for iOS 27 and ready for iPhone Duo on day one, and it comes with a long list of improvements of its own. Too many to list them all, so here are the highlights:

- **Expo Modules 2.0 (beta)** \- plain Swift and Kotlin classes with annotations, with sync calls 2.5-5.6x faster than the DSL on iOS and faster than TurboModules in all twelve Android microbenchmarks.
- **Faster builds and faster modules** \- prebuilt `expo-modules-core` Android libraries cut a clean four-ABI debug build from about 80 seconds to about 39, and iOS calls passing long strings are up to 3.8x faster.
- [**App Intents**](https://expo.dev/blog/introducing-expo-app-intents) **(alpha)** \- `expo-app-intents` exposes your app to Siri, Shortcuts, Spotlight, and Apple Intelligence.
- **Expo UI and Android home screen widgets** \- lists recycle rows now, iOS gains NavigationStack and Toolbar, and `expo-widgets` runs on Android with its own Hermes runtime.
- **A CLI built for agents** \- the experimental `@expo/agent-cli` wraps Expo CLI, EAS CLI, and `expo-doctor`.
- **Expo Router** \- data loaders, SSR and middleware are now stable, alongside native tabs and a reworked navigation core.

And a few more: an experimental Rust transformer for roughly 2x faster cold bundling, SwiftPM groundwork for Expo apps, and Expo Observe gaining control over automatic error recording.

## 🔀 Other {#other}

- 📣 [Experimental soft navigation metrics now available in CrUX](https://web.dev/blog/crux-experimental-soft-navs/) \- Exciting news for SPA / client-side routing frameworks\! Core Web Vitals takes into account soft navigations, measuring the full navigation session instead of only the initial page load, and the Chrome User Experience Report dataset now exposes these metrics as experimental. Use the [CrUX Vis](https://cruxvis.withgoogle.com/#/?view=cwvsummary&url=https%3A%2F%2Freact.dev%2F&identifier=origin&device=PHONE&periodStart=0&periodEnd=-1&display=p75s) tool and check the “Include soft navigations” toggle to see the score impact on any site. The React site’s score is improving because subsequent navigations are faster than the initial page load.
- 🔐 [PHP \- Critical remote code execution vulnerabilities](https://www.php.net/archive/2026.php#2026-10-21-5) \- These 2 “php2shell” RCEs look really bad: no login needed, affecting PHP since 5.4. Yes, that includes your WordPress and Laravel sites. Upgrade now\!
- 📜 [The Future of CSS](https://www.joshwcomeau.com/css/interop-2027/) \- Josh Comeau’s top 10 picks for Interop 2027, nicely presented with browser support and interactive demos.
- 📜 [JPEG XL vs AVIF for web use-cases](https://jakearchibald.com/2026/jpeg-xl-vs-avif/) \- JPEG XL recently landed in all browsers. AVIF remains better for lossy compression, but JPEG XL wins for lossless compression and recompressing existing JPEGs.
- 📦 [TypeScript 7.1 beta \- New TypeScript API, Import Attributes in Ambient Modules, stable `es2026` lib/target, performance improvements](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/) \- The real highlight is the new TypeScript API, unlocking ecosystem tools such as TypeScript-ESLint to integrate with TypeScript 7. Content Mappers are a game changer for improving the type safety of external files such as MDX, Astro, CSS Modules, Vue, and more.
- 📦 [tsrs \- Rust port of the TypeScript 7 type checker and LSP](https://blog.cloudflare.com/typescript-rust-port/) \- There have been a lot of TypeScript ports to Rust recently. The most promising one is already much faster than tsgo. It’s now supported by Cloudflare/VoidZero, incubating under the Oxc toolchain umbrella. Not a fork: they are actively collaborating with the TypeScript team and plan to keep it aligned with the reference implementation. The [backstory](https://building.owner.com/tsrs) is also interesting, and shows the port will also speed up Oxlint type-aware linting.
- 📦 [Node.js 24.22 LTS \- `util.throttle()` and `util.debounce()`, crypto improvements](https://nodejs.org/en/blog/release/v24.22.0)
- 📦 [Rsdoctor 2.0 \- Now Rspack-only, Agent CLI, 57% faster analysis, 56% smaller install, multi-compiler reports](https://rsdoctor.rs/blog/release/release-note-2_0)
