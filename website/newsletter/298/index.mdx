## ⚛️ React {#react}

- 👀 [React docs \- New `<img>` API ref page](https://react.dev/reference/react-dom/components/img) \- The humble image component does more than just displaying images. It also generates preload hints during SSR by default, and integrates nicely with `<ViewTransition>` animations.
- 👀 [React Flight PR \- Server References for arbitrary object types](https://github.com/react/react/pull/37636) \- Experimental Flight protocol feature, enabling Server References to point to an object and not just a function.
- 🔐 [Next.js 16.3.6 \- Security Update](https://nextjs.org/blog/nextjs-security-update-september-22-2026) \- Fixing a critical remote code execution vulnerability for those using `ImageResponse` with the Node runtime with dynamic user-controlled SVG inputs.
- 🗓️ [React Advanced London](https://reactadvanced.com/?utm_source=thisweekinreact) - 🇬🇧 London - 23 & 26 Oct. Last call for London's most in-depth React conference! Two days, 50+ advanced sessions, next to Big Ben. Don't miss it—get 10% off with code "TWIR.
- 📜 [Do Frameworks Matter Anymore?](https://brookslybrand.com/posts/do-frameworks-matter-anymore/) \- If LLMs are great at React but nobody reads the `.tsx` files anymore, why even use an abstraction? Will the industry stick with React forever, or is there room for platform primitives (Web Components) and new ideas (Remix 3)? Kinda related to my existential crisis. 😆
- 📜 [React Activity: When A Render No Longer Guarantees an Effect](https://hackernoon.com/react-activity-when-a-render-no-longer-guarantees-an-effect) \- Blindly replacing conditional rendering with `<Activity>` can expose subtle bugs in legacy code relying on the render/Effect/cleanup sequence.
- 📜 [Frontend for systems engineers](https://tj-zhang.com/blog/frontend-for-systems-engineers/) \- Explains React through familiar systems concepts
- 📦 [Astro React 7.0 \- Replaces Babel with Oxc, upgrades to Vite Plugin React v6](https://docs.astro.build/en/guides/integrations-guide/react/#upgrading-the-react-integration-to-v700) \- It now has opt-in support for the React Compiler through Oxc experimental support.
- 📦 [React Redux 9.4 alpha \- `useSignalSelector()` hook, `<SignalProvider>` component, `react-redux/signals` entrypoint](https://github.com/reduxjs/react-redux/releases/tag/v9.4.0-alpha.0) \- Drop-in optimization for large apps with thousands of connected components. Opt-in, but \+7kB gzip. A proxy tracks selector state access, so only affected selectors re-run on dispatch.
- 📦 [Redact 0.1 \- Add React 19.3 APIs, improve runtime compatibility, keep sync rendering contract](http://releases)\- TanStack's lightweight, synchronous reimplementation of React is now on GitHub and ships its first minor.
- 📦 [React Three Fiber 9.8 \- Support for React 19.3, roots configured synchronously, Strict Mode fixed](https://github.com/pmndrs/react-three-fiber/releases/tag/v9.8.0) \- For 3D enthusiasts, Poimandres also released [Glyph](https://github.com/pmndrs/glyph), a GPU-first typography engine with R3F bindings.
- 📦 [TanStack React Hotkeys 0.11 \- Improved physical key support, recorder validation, conflict detection, cross-layout fixes](https://github.com/TanStack/hotkeys/releases/tag/%40tanstack%2Freact-hotkeys%400.11.0)
- 📦 [React Simple Maps 5.0 \- Composable SVG map charts for data visualization in React](https://www.react-simple-maps.io/)
- 📦 [React Resizable Panels 4.13 \- Deferred panel resizing, panel expand/collapse threshold](https://bsky.app/profile/bvaughn.me/post/3mvxpohs3vs2n)
