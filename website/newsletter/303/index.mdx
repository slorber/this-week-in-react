## ⚛️ React {#react}

![TanStack Redact](/emails/issues/303/redact.jpg)

[**TanStack Redact**](https://tanstack.com/blog/introducing-tanstack-redact)

Tanner Linsley's AI-driven React projection experiment is now a real TanStack project adopted in production. Redact is a smaller React-compatible runtime for the browser. Already working with Start, Next.js, Vinext, and Vite. On the server, nothing changes: React still handles SSR and Server Components.

Although it’s smaller, the main tradeoff is that Redact renders synchronously, without React's time slicing features. The blog post acknowledges that “a heavy render can still delay input”.

## 📱 React-Native {#react-native}

![React Native on Desktop](/emails/issues/303/expo-desktop.jpg)

**React Native on Desktop**

React Native on macOS and Windows had a big week, with 3 related releases:

📦 [**React Native Windows 0.85**](https://devblogs.microsoft.com/react-native/react-native-windows-v0-85-is-here/) is out, completing the move to the New Architecture.

📦 [**Expo Desktop v1**](https://expo-desktop-docs.vercel.app) is an independent project from Jamie Birch, not endorsed or maintained by Expo:

- Best-effort macOS and Windows support for Expo apps: create an app with `npx expo-desktop create-app`, then run Prebuild, CNG, and `run macos/windows` commands
- One Expo codebase targets iOS, Android, web, macOS, and Windows
- Currently running on Expo SDK 55 until the native macOS (RN 0.83) catches up.

📦 [**Legend Spark**](https://legend.so/spark) is a desktop framework from Jay Meistrich built right on top of it, aiming to ease the migration from Electron/Tauri:

- Desktop modules included: window management, menu bar icons, and friends
- No Xcode or native build to get started: new apps open in a prebuilt runner, like Expo Go for desktop. Upgrade to a custom build when you need new modules or want to publish.
- Patches libraries that don't support desktop yet
- Dogfooded: all of the Legend apps (Diff, Code, Music, Chat History, Photos) already run on Spark.
- Windows support in progress.
