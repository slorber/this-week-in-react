## ⚛️ React {#react}

![Next.js 16.4](/emails/issues/300/next.jpg)

[**Next.js 16.4**](https://nextjs.org/blog/next-16-4)

Cache Components are reaching maturity, now recommended for every Next.js app. The new programming model is enabled by default in `create-next-app`, and will become the default in v17. Partial Prefetching is now considered part of the model.

Alongside this milestone, this release introduces:

- Static output guarantees: `export const ensureStatic`: fail the build if dynamic content sneaks into a route's shell, prefetch, or navigation.
- Granular prefetching control: `await navigation()` to exclude content from a prefetch.
- Agent-guided upgrades and feedback.
- React 19.3: stable View Transitions, Fragment Refs, `browser()` API.
- Faster experimental Rust React Compiler.
- Many DX, Turbopack and bundle improvements.

## 📱 React-Native {#react-native}

![Skia 3.0](/emails/issues/300/skia.jpg)

🎥 [**React Native Skia 3.0 \- Hello Graphite**](https://www.youtube.com/watch?v=L-PNQi1nBSA)

William Candillon just shipped the biggest release of React Native Skia to date\!

Version 3.0 is rebuilt on **Skia Graphite**, Skia's new backend for modern GPU APIs. The old OpenGL-centric design came with stability and performance pains. Graphite fixes both. And because its design is symmetric with WebGPU, Skia and the rest of the web ecosystem can now run together on the same GPU.

Here's what that brings:

- **Multi-threading by default** \- A Skia drawing can be created on any dedicated thread. Only presenting the work runs on the UI thread.
- **Symmetric with WebGPU** \- React Native Skia and React Native WebGPU share the same WebGPU instance.
- **Zero-copy Three.js interop** \- A Three.js scene can be used as a regular Skia image with Skia effects on top, and Skia can draw onto Three.js scenes.
- **Video & camera on GPU** \- `importExternalTexture` brings video and camera feeds into Skia zero-copy, easy on the battery.
- **Lottie on WebGPU** \- Customizable Lottie animations, now with video imports.
- **Android platform work** \- An experimental CanvasView (API 29+) and view snapshotting over WebGPU.

The release is mostly backward compatible with v2, except for the system requirements: Android minSDK is now 26, and OpenGL is no longer supported (Vulkan only).

Shopify will keep [sponsoring the project until the end of the year](https://x.com/mustafa01ali/status/2107530860555608339), despite migrating its apps away from React Native.
