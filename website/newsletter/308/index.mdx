## 💸 Sponsor {#sponsor2}

[![Meet React Nitro](/emails/issues/308/nitro.jpg)](https://www.react-nitro.com/?utm_source=margelo_newsletter&utm_medium=email&utm_campaign=react_nitro_alpha&utm_content=sponsor_ad)

**[Meet React Nitro](https://www.react-nitro.com/?utm_source=margelo_newsletter&utm_medium=email&utm_campaign=react_nitro_alpha&utm_content=sponsor_ad)**

React Nitro is Margelo's next-generation framework for building native iOS and Android apps with React. The renderer has been designed from the ground up to render real native views, recycle List cells and pre-process TextInputs fully synchronously on the UI Thread.

Most core modules are pre-compiled with Static Hermes FFI, which drastically speeds up rendering and app launch times. Nitro V1 powers the bridge between JavaScript and native and exposes native components or modules with minimal overhead.

Ask your agent to get started with [React Nitro](https://www.react-nitro.com/?utm_source=margelo_newsletter&utm_medium=email&utm_campaign=react_nitro_alpha&utm_content=sponsor_ad) today!
