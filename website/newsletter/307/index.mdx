## 📱 React-Native {#react-native}

![Reanimated 4.8](/emails/issues/307/reanimated-48.jpg)

[**Reanimated 4.8 \- Shared Element Transitions stable**](https://swmansion.com/blog/shared-element-transitions-in-reanimated-4-8-0/)

One of the most anticipated features is finally stable, and enabled by default\! Tag two views with the same `sharedTransitionTag`, put them in two `<SharedTransitionBoundary>` components, and when the target boundary becomes active, the view travels to it. Think of an album cover moving from a song list into the now-playing screen. It's a small detail, but it makes transitions feel much more natural.

Transitions are no longer tied to navigation, so they also work between tabs, or between two views on the same screen. The moving view is the actual view, not a snapshot, so its content keeps running during the transition. On iOS, it even follows your finger during a swipe-back gesture. When the two views have different children, the new `SharedTransition.fadeContent()` modifier fades them out and in.

Other key highlights include:

- **Animated text** \- Support for `<Animated.Text>{sharedValue}</Animated.Text>`. The UI thread updates text without any React re-render.
- **CSS animations** \- CSS animations and transitions interpolate `backgroundImage` gradients, and can animate `borderCurve`, `writingDirection`, `verticalAlign` and `objectFit`.
- **Lighter animations** \- Cutting a lot of unnecessary work from every frame.
- [**Worklets 0.14** \- WebSocket on Worklet Runtimes, abortable runtimes, `runOnRNSync` from other runtimes, new docs with a visual Learn section](https://github.com/software-mansion/react-native-reanimated/releases/tag/worklets-0.14.0) \- Supports React Native 0.87 → 0.89, pairs with Reanimated 4.8.x
