## ⚛️ React {#react}

![Vercel UI SDK beta](/emails/issues/306/ui-sdk.jpg)

[**Vercel UI SDK beta \- Headless UI behaviors for agents to build components**](https://ui-sdk.dev/docs/core/changelog/introducing-ui-sdk)

This new SDK includes 50+ accessible, composable behaviors like `createPopup`, `createTypeahead` or `createRovingFocus`. Your agent combines them to build your own components. It also ships 50+ unstyled components for React, Vue, Svelte, Solid and Web Components. And agents can use the UI too: with `createAgent()` or WebMCP, they read the page and press, type and pick directly, without screenshots.

It's not the first time we've seen behaviors extracted out of component libraries: React Aria has headless hooks, and Chakra UI has Zag state machines. But this one looks quite promising, in particular for the agentic era.

## 📱 React-Native {#react-native}

![Expo Simulators](/emails/issues/306/expo-simulators.jpg)

**Mobile development is being rebuilt for agents**

Coding agents are becoming the primary users of our development tools, and the infrastructure is being rebuilt around them. The bottleneck is no longer writing code: it's verifying, building, and shipping it.

Expo just launched [Expo Simulators](https://expo.dev/blog/introducing-expo-simulators-cloud-simulators-built-for-agents): cloud iOS Simulators and Android Emulators that any agent can drive. Each session runs on an isolated VM so parallel agents never collide, and streams live to the browser where you can watch or take over.

Key callouts:

- **Proof on the PR** \- every session ends with a recording, screenshots, and logs the agent can attach, so instead of skimming a diff and trusting it looks right, the reviewer watches the change working.
- **Agents with eyes** \- an agent can run the app it just built, spot visual issues like overflowing labels, and fix them in the same session.
- **Runs where agents run** \- sessions start from cloud sandboxes, CI, or Linux and Windows machines, and self-terminate on timeout.
- **Framework-agnostic** \- any app that builds for a simulator runs: Expo, SwiftUI, Flutter, Unity, or anything else.

Exact, the new agent-native Rust framework from Expo, introduced two services in alpha: [Exact Build](https://exact.appdrop.app/), a high-speed Linux-based iOS build service, and [AppDrop](https://appdrop.app/), which signs and installs any iOS app. Together with Expo Simulators they close the loop: an agent takes an issue, writes the code, builds it, verifies it on a cloud simulator, and ships it to your phone, while humans move up to reviewing evidence.
