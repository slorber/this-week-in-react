This week, X explained how it rebuilt its flagship app with streaming SSR, Suspense and Relay. e18e launched independent benchmarks for 9 meta-frameworks.

On mobile, Discord follows Shopify and leaves React Native for native and Rust. Meanwhile, Expo’s co-founder previewed Exact, an agent-native app framework written in Rust. We also have many releases: Audio API 1.0, Bottom Sheet 0.18, Keychain 11, Gesture Handler 3.5…

Elsewhere, Node.js shipped security releases and detailed what the v27 alpha V8 upgrade unlocks. Safari 27.3 beta brings Temporal and `using` to all browsers!

Let's dive in!
