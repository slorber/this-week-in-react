## ⚛️ React {#react}

![TanStack Start 1.0](/emails/issues/301/tanstack-start.jpg)

[**TanStack Start 1.0**](https://tanstack.com/blog/tanstack-start-1-0)

The full-stack framework is officially stable and production-ready, supporting both React and Solid. It has already been used on millions of apps during its beta/RC phase. As its 𝕏 [launch video](https://x.com/tan_stack/status/2110022759338422327) puts it: "Feels like building a SPA. With the whole server behind you".

- **Client-first:** SPA-style routing, state and caching, with server rendering, streaming and typed server functions.
- **Type-safe end to end:** route params, search params, loader data and server function inputs are all typed, keeping changes consistent for both humans and agents. Type checking speed has been thoroughly optimized.
- **Agent-ready:** packages ship TanStack Intent skills, so agents can learn Start's APIs and best practices.
- **RSC is opt-in:** supported, but the team removed it from tanstack.com because it made the codebase harder to reason about.
- **Deploy anywhere** with Vite and Nitro. Rsbuild is also supported.
