[![Panda CSS 2.0 - Same styling API, a new engine underneath](/emails/issues/299/panda.jpg)](https://panda-css.com/blog/panda-css-v2)

**[Panda CSS 2.0 \- Same styling API, a new engine underneath](https://panda-css.com/blog/panda-css-v2)**

This new major version of the type-safe, build-time CSS-in-JS library is the biggest update since launch. Here’s what you need to know:

- The CSS authoring experience doesn't change much.
- The compiler has been rewritten in Rust on top of Oxc.
- DX and builds get dramatically faster, and output better CSS.
- With source transforms, Panda integrates with the bundler so that `css()`, style props, recipes and patterns are compiled to plain class strings at build time. [The styling runtime disappears from your bundle](https://panda-css.com/blog/zero-runtime-all-the-way-down), not just the style-insertion logic.
- You get many new features to play with: a [typography preset](https://panda-css.com/blog/typography-preset), publishing your Panda design system and [visualize it in Studio](https://panda-css.com/blog/see-your-design-system), new CSS functions, a better CLI, an official ESLint plugin, and more

**[Vinext 1.0 \- Next.js applications, powered by Vite](https://blog.cloudflare.com/vinext-nextjs-on-vite/)**

Cloudflare's Vite-based reimplementation of Next.js goes stable, supports both App and Pages Router and claims 99%+ compatibility with the Next.js test suite (minus Cache Components). They also have a different opinion of how ISR should work.

What started as a one-off slopfork experiment is now becoming an AI-driven software factory able to keep up with new features landing in the official Next.js implementation. Interesting time\!

## 🔀 Other {#other}

- 🐦 [TC39 meeting live updates \- Progress for Composites, Iterator methods, export defer, and more](https://x.com/search?q=from%3Arobpalmer2%20ECMAScript%20excitement&src=typed_query&f=live) \- Among many other interesting JS proposals, my favorite one progressed\! Composites are objects compared by value instead of identity, using interning. This is kind-of the “new version” of the former Records & Tuples proposal.
- 👀 [WebSkills](https://github.com/kevinmoch/web-skill) \- A Huawei contributor recently pitched this at a W3C seminar, and W3C could incubate the project for a future standardization. Agent Skills, stored in the browser, running scripts in Web Worker sandboxes. Very early, but this could complete WebMCP and On-Device AI.
- 📜 [Optimizing objects with null prototypes](https://adventures.nodeland.dev/archive/optimizing-objects-with-null-prototypes/) \- Using null-prototype objects in hot paths can be a perf bottleneck for V8. Matteo works on Node.js WebStream optimisations, and just changing how those objects are created led to significant perf improvements.
- 📜 [CSS linked parameters \- One SVG, nine posters](https://pepelsbey.dev/articles/svg-link-params/) \- Upcoming CSS feature to style an `<img>` SVG directly from the page CSS. Can be used today as a progressive enhancement.
